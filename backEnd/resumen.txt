Papelería Sofía - Backend

Este es el backend del proyecto Papelería Sofía, una app web desarrollada en Node.js con Express, Prisma ORM y Zod, con almacenamiento de imágenes y autenticación JWT.

Papelería Sofía es un emprendimiento local dedicado a la venta de artículos escolares, de oficina y servicios de impresión y encuadernación. Esta aplicación tiene como objetivo digitalizar su catálogo de productos, permitir a los clientes hacer pedidos personalizados de impresiones, y facilitar la gestión interna desde un panel de administración privado.

🧱 Estructura del Proyecto
✨ Tecnologías principales:
Node.js + Express como backend

Prisma ORM (con MySQL)

Zod para validación de datos

JWT para autenticación de usuarios

Multer + Sharp para carga y optimización de imágenes

REST Client (VS Code) + formularios HTML para pruebas

📁 Organización de Carpetas
controllers/ → lógica de cada recurso (producto, usuario, consulta, etc.)

routes/ → define endpoints Express

services/ → lógica de base de datos usando Prisma

schemas/ → validaciones con Zod (separadas para create/update, etc.)

middlewares/ → auth.js, multer_IMG.js, validadores

libs/ → prisma.js (con $extends()), JWT, mailer

utils/ → funciones como manejarError, generarToken, etc.

public/imgs/ y public/thumbs/ → imágenes originales y miniaturas

🔐 Autenticación
Registro y login usando JWT

Encriptación de contraseñas con bcrypt

Middleware para proteger rutas (verificarToken, soloAdmin)

Login devuelve token para usar en headers

👤 Usuario
CRUD completo para usuarios (admin)

Validación con Zod

Roles (ADMIN, CLIENTE, EMPLEADO)

Registro automático al hacer pedido si no existe

📦 Productos
Alta de productos con imágenes (formulario HTML)

Validación con Zod

Subida de imágenes con multer.memoryStorage

Optimización de imágenes con sharp

Varias imágenes por producto (ImagenProducto)

Listado con imágenes incluidas

Actualización parcial con imagen opcional

🎯 Categorías
Enum CategoriaProducto definido en Prisma

Endpoint /api/categorias para obtener las categorías disponibles

Formulario HTML que carga el select automáticamente

El select queda seleccionado automáticamente al editar un producto

🛒 Pedidos
Endpoint para crear pedidos con usuario incluido

Si el usuario no existe → lo crea

Si ya existe → lo reutiliza

Validación completa con Zod

Historial de cambios de estado en HistorialEstadoPedido

$extends() intercepta pedido.update y guarda el historial

📨 Consultas
Endpoint público para enviar una consulta

Admin puede:

Marcar como leída

Marcar como resuelta

Responder

Validaciones con Zod

Campos leido, resuelto, respuesta

Actualizaciones de estado parciales

🎁 Promociones
Carga de promociones con múltiples imágenes y productos asociados

Tabla intermedia PromoProducto (muchos a muchos)

Tabla ImagenPromocion

Validación con Zod

Verificación de existencia y stock de productos antes de vincular

Listado de promociones con imágenes y productos incluidos

📂 Archivos REST Client (.http)

consulta.http → crear, listar, responder

pedido.http → crear, listar, cambiar estado

auth.http → login y registro

producto.http → listar, eliminar (crear y actualizar se hacen con formulario HTML)

🧪 Formularios HTML de prueba
producto-crear.html → alta de producto (con 1 o varias imágenes)

producto-editar.html → lista productos, permite seleccionar uno y editar

Carga automática de datos del producto

✅ Modularización clara y mantenible
